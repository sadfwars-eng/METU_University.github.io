METU | Русский язык C1 — версия 11

Сайт создан на основе дизайна, предоставленного пользователем. Две отдельные учебные программы: Syllabus 1 (15 тем, 4 модуля) и Syllabus 2 (15 тем, 3 модуля). Вторая программа составлена по предоставленному PDF «силлабус_rus.pdf» (весенний семестр); 54 экзаменационных вопроса включены в раздел справки.

Файлы index.html, style.css, script.js, content.js, syllabus2.js, topics.js, изображения и значки должны лежать в корне репозитория GitHub Pages. Откройте index.html для локальной проверки.

Вкладка браузера использует favicon.ico / favicon-32.png. Подпись: Тукебаева Жаныл Аубакировна — ассоциированный профессор.

Защита от обычного копирования действует на учебные тексты и справочные материалы; она НЕ предотвращает просмотр исходного кода, сохранение страницы, скриншоты и копирование через инструменты разработчика. Оригинальный PDF не включён в публичные файлы, поскольку любой размещённый публично PDF можно скачать.

У Syllabus 2 указаны ссылки на поиск видео, поскольку проверенные конкретные видео для каждой темы не были предоставлены. У Syllabus 1 сохранены прежние видео и внешние ссылки. Фото профессора загружается по внешнему адресу и требует подключения к интернету.

Неофициальный учебный проект, не официальный сайт университета. Учебные материалы и ссылки рекомендуется проверить преподавателю перед публикацией.
