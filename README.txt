METU Academic Edition v8

Оригинальный сдержанный университетский дизайн. Слева навигация по 4 модулям и 15 темам. Все подробные материалы из предыдущей версии сохранены. Видео: встроенные там, где есть подтверждённые embed-ссылки; для остальных — ссылки. Прогресс сохраняется локально в браузере. Миниатюрная ссылка «😏 ответы» в шапке открывает мем.

Для публикации на GitHub Pages загрузите все файлы из архива в корень ветки main. В Settings → Pages выберите main / (root).
