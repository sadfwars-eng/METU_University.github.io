METU · Русский язык C1 — учебный портал

Эта версия сверстана по структуре и визуальному стилю сайта-примера:
- темно-синяя шапка с золотой линией;
- кремовый фон, бордовые акценты и академические шрифты;
- навигация сверху и боковая панель разделов;
- вкладки «Главная», «План курса», «Материалы», «Литература», «Экзамен», «Книги», «Помощник курса».

Содержание
- 15 тем из силлабуса;
- теория, пример, подсказка преподавателю, практические вопросы;
- для каждой темы собственная анимированная мини-схема;
- встроенные видеоплееры там, где в материалах темы есть ссылка на видео;
- отдельные СРС и СРСП;
- уникальный мотивационный блок в самом конце каждой темы;
- 60 экзаменационных вопросов, поиск и локальные отметки прогресса;
- список литературы из силлабуса и дополнительные книги для чтения.

Как открыть
1. Распакуйте ZIP в отдельную папку.
2. Откройте index.html в браузере.
3. Для внешних видеороликов, ссылок и загрузки веб-шрифтов нужен интернет. Основные тексты, схемы и интерактивность работают локально.

Важно
Помощник курса — локальный поиск по встроенным материалам, а не подключенная внешняя ИИ-модель. Это позволяет не размещать секретный API-ключ в публичном JavaScript. Учебные ссылки иногда могут меняться со стороны своих сайтов.
