METU — университетский учебный сайт (версия 9)

Основа оформления: предоставленные пользователем index.html, style.css, script.js, topics.js.
Сохранены модули и карточки тем; добавлены подробные материалы из ранее созданной версии, навигация, прогресс и компактная секретная кнопка 😏.

Файлы: index.html, style.css, script.js, topics.js, content.js, logo-shield.png, logo-full.png, meme-popalsya.jpg.

Публикация GitHub Pages: загрузите содержимое архива в корень репозитория (не саму папку), затем Settings → Pages → Deploy from a branch → main → /(root).

Видео YouTube и Rutube встраиваются там, где имеются ссылки на ролики. Остальные темы содержат ссылки на внешние учебные материалы; для них ещё нужны проверенные видеоролики.
Фото преподавателя загружается с внешнего сайта и требует интернет; если ссылка недоступна, появляется нейтральная заглушка.
Прогресс сохраняется в localStorage этого браузера на этом устройстве.

Важное замечание: учебные материалы требуют содержательной проверки преподавателем перед использованием на занятии.
