METU · Учебная студия преподавателя (версия 7)

1. Распакуйте ZIP.
2. Откройте index.html для предварительного просмотра.
3. Загрузите СОДЕРЖИМОЕ архива в корень репозитория GitHub (рядом с index.html), не сам ZIP.
4. Settings → Pages → Deploy from a branch → main → /(root) → Save.

Включены 15 тем, теория, примеры, вопросы, задания, видео/источники, мотивация, навигация, сохранение прогресса и мем.
Фото преподавателя пока загружается из внешнего источника, поскольку исходный файл фотографии не предоставлен.
Для части тем доступна ссылка на материал, но нет подтверждённого встраиваемого видео.
Сайт — независимый учебный проект, а не официальный сайт METU.
