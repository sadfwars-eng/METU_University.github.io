METU v14 — две программы и электронные книги.
Откройте index.html или разместите ВСЁ содержимое ZIP в корне GitHub Pages.
Инструкция по использованию на главной странице.
30 тестов по 15 вопросов. Тесты построены на распознавании утверждений из учебных материалов темы; перед использованием как официальной аттестации преподавателю нужно проверить формулировки.
После отправки ответы сохраняются в localStorage конкретного браузера. Это НЕ серверное хранение и НЕ защита от обхода через очистку данных или другой браузер.
Просмотр книг: страницы из двух предоставленных документов, водяной знак METU, без заявлений об официальной защите.
Публичные материалы и изображения нельзя полностью защитить от извлечения.
Изображение преподавателя предоставлено пользователем.


Версия 15: в каждой из 30 тем четыре обязательных задания (конспект, пересказ, презентация, отправленный тест). Первые три — отмечаются студентом вручную, четвёртое — автоматически после отправки теста. Прогресс сохраняется отдельно для каждой темы/силлабуса в localStorage. «Тема полностью выполнена» ставится только при 4/4. Без регистрации и серверной проверки.
